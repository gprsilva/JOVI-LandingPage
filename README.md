# JOVI — Landing Page

Landing page do projeto **JOVI**, uma câmera inteligente que usa IA contextual para ajudar estudantes a capturar lousas, slides e documentos com clareza, sem etapas de configuração manual. Desenvolvida pela equipe **Drakon**.

## Sobre o projeto

A página apresenta o problema que o JOVI resolve, as três soluções da IA (AdaptAI, Smart-Pop e JoviEdu), o público-alvo, uma galeria da experiência do produto, a equipe responsável e um canal de contato.

## Seções

- **Hero** — vídeo com efeito de scroll e apresentação do produto
- **Problema** — dificuldades ao registrar conteúdo em contextos de estudo
- **Soluções** — AdaptAI, Smart-Pop e JoviEdu
- **Público-alvo** — persona representando o usuário principal
- **Galeria** — destaques visuais da experiência
- **Nossa equipe** — apresentação dos integrantes da Drakon
- **Contato** — formulário de mensagem e canais (e-mail, Instagram, LinkedIn)
- **Seletor de tema** — Blue, Purple e Black

## Tecnologias

- HTML5 semântico
- CSS3 (Grid, responsividade Desktop/Tablet/Mobile)
- JavaScript (vanilla)

## Como executar

```bash
git clone https://github.com/gprsilva/JOVI-LandingPage.git
cd JOVI-LandingPage
```

Depois, basta abrir o `index.html` no navegador ou usar uma extensão como o Live Server (VS Code).
